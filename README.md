# The Billion-Dollar Myth — Director's Cut

> **An independent research project exploring how audience behaviour, attention economics and changing distribution models are reshaping how success is measured in modern entertainment.**

Rather than predicting the future of cinema, this paper examines whether traditional performance metrics still describe the systems they were originally designed to measure.

Using publicly available information and a systems-thinking approach, it explores audience behaviour, streaming, gaming, attention and commercial interpretation.

## Why I built this

To demonstrate how structured analysis can transform complex, ambiguous information into clear, evidence-based insight for decision-makers.

Although the entertainment industry provides the case study, the project is fundamentally about analytical reasoning, evidence-led thinking and communicating complex ideas clearly.
